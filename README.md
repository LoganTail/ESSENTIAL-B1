# DONNER ESSENTIAL B1

This repository contains firmware feature guides for the DONNER ESSENTIAL B1. Each firmware version has its own folder with separate English and Simplified Chinese guides.

本仓库收录 DONNER ESSENTIAL B1 固件功能使用指南，按固件版本组织，提供英文和简体中文版本。

| Firmware / 固件版本 | English | 简体中文 |
|---|---|---|
| V1.2.0 | [Feature Guide](V1.2.0/USER-GUIDE-EN.md) | [新增功能使用指南](V1.2.0/USER-GUIDE-ZH.md) |

The V1.2.0 guides cover Pattern randomization, Song Mode, BPM Nudge, external clock playback rates, global settings, and mode switching.

V1.2.0 指南涵盖 Pattern 随机化、Song Mode、BPM Nudge、外部时钟速度倍率、全局设置和模式切换。
